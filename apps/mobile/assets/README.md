# Originele merkassets

`brand-mark.svg` is het bewerkbare originele TuinWerk-beeldmerk (plant en technische moer), gemaakt voor dit project zonder externe stockasset. `icon.png` is 1024×1024 RGB zonder alphakanaal; `adaptive-icon.png` heeft een transparante voorgrond met veilige marge; `splash.png` is het losse merkteken. De Play-store-assets staan in `../store/`.

Store-screenshots moeten nog van de echte getekende app worden opgenomen. Deze grafische assets zijn geen screenshots of bewijs van fysieke apparaatwerking.
